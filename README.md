# 📝 Editor MDI – Windows Forms Application (C#)

## 📌 Descriere generală

**Editor MDI** este o aplicație desktop dezvoltată în C# folosind Windows Forms, care implementează arhitectura **Multiple Document Interface (MDI)**. Aplicația permite gestionarea simultană a mai multor documente text într-o singură fereastră principală.

Proiectul evidențiază concepte fundamentale din dezvoltarea aplicațiilor desktop:

- utilizarea unui container MDI  
- crearea dinamică a ferestrelor copil  
- manipularea controalelor UI (MenuStrip, ToolStrip, TextBox)  
- gestionarea evenimentelor  
- salvarea fișierelor folosind `System.IO`  
- modificarea dinamică a proprietăților fontului  

Fiecare document este deschis într-o fereastră separată și poate fi editat independent, iar utilizatorul poate personaliza fontul, dimensiunea și stilul textului.

## ⚙ Funcționalități principale

- Creare documente multiple
- Aranjare ferestre (Cascade / Tile)
- Salvare documente în format `.txt`
- Selectare font și dimensiune
- Activare / dezactivare stil Bold
- Shortcut `Ctrl + S` pentru salvare

---

## 🏗 Tehnologii utilizate

- C#
- .NET (Windows Forms)
- System.Drawing
- System.IO

## 🎯 Scopul proiectului

Acest proiect are scop educațional și demonstrează implementarea unei aplicații MDI funcționale, punând accent pe organizarea codului, lucrul cu interfața grafică și gestionarea documentelor multiple într-un mediu desktop.
